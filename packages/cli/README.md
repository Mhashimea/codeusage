# CodeUsage CLI

Track your team's AI coding tool usage with zero friction.

## Install

```bash
npm install -g codeusage-cli
```

## Setup

```bash
codeusage init
```

## Uninstall

```bash
npm uninstall -g codeusage-cli
```

## Documentation

For full documentation, visit [https://codeusage.dev/docs](https://codeusage.dev/docs)
