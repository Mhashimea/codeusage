🔒
Privacy-First Design
Prompt content never leaves developer machines. Blocked prompts are not logged or reported to Afterburn. This feature protects developers from accidental credential exposure — it's not a monitoring or compliance tool.
🚧
Coming in v0.4
Custom patterns — define your own regex patterns for organization-specific credentials.
This is a separate page at /app/guard. The sidebar shows Prompt Guard as a top-level nav item. Custom patterns section is reserved for v0.4.
2. CLI — Blocked Prompt Warning

What the developer sees when a prompt containing a credential is blocked.

Terminal — Claude Code session
$ claude
Claude Code v1.0.3
Working directory: ~/projects/my-app
> Here's my database config:
DATABASE_URL=postgresql://admin:s3cr3tP@ss@db.example.com:5432/prod
──────────────────────────────────────────────────────────────
⚠ afterburn · prompt blocked
──────────────────────────────────────────────────────────────
Reason: PostgreSQL connection string detected
Pattern: Database URL — Postgres
Your prompt was not sent to Claude Code.
Remove the sensitive value and try again.
──────────────────────────────────────────────────────────────
> _
Alternative: AWS Key
Terminal
> Deploy using AKIAIOSFODNN7EXAMPLE
──────────────────────────────────────────────────────────────
⚠ afterburn · prompt blocked
──────────────────────────────────────────────────────────────
Reason: AWS access key ID detected
Pattern: AWS Access Key
Your prompt was not sent to Claude Code.
Remove the sensitive value and try again.
──────────────────────────────────────────────────────────────
The matched value (actual password/key) is never displayed back. We only show pattern name. This prevents shoulder-surfing exposure.
